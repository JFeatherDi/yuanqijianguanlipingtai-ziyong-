# IOTAT 实验室元器件管理平台

一个面向实验室的轻量级元器件库存管理平台，专为低配服务器（≥350M 内存 / ≥4G 存储）设计。

## ✨ 功能

- **登录**：固定账号 `IOTAT` / 密码 `swust350351`
- **元器件列表**：分类、名称、规格、单位、位置、当前库存、预警值
- **新增 / 编辑 / 删除** 器件
- **入库**：选器件 → 输入数量 → 库存 +
- **出库 / 使用**：选器件 → 输入数量 → 库存 -（自动校验库存）
- **批量导入**：支持 Excel (`.xlsx`) / CSV
- **导出 CSV** / **下载导入模板**
- **出入库流水**：所有变更记录可追溯
- **库存预警**：低于预警值红色高亮

## 🧱 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 原生 HTML + CSS + JS | 单文件、零依赖、零 CDN，加载极快 |
| 后端 | Flask 3.x | 单文件路由，轻量 |
| WSGI 服务器 | waitress | 生产级，限制并发线程防止进程堆积 |
| 数据库 | SQLite (WAL 模式) | Python 内置，读写并发不互锁 |
| 表格解析 | openpyxl | 仅用于 xlsx |

内存占用：常驻约 30-50MB，完全适配 350M 内存服务器。

## 🛡️ 并发与安全

针对多人同时使用场景做了专门优化：

- **SQLite WAL 模式**：读不阻塞写，写不阻塞读，并发性能提升数倍
- **原子出库**：`UPDATE ... WHERE stock >= ?` 单语句完成扣减，多人同时出库最后一件不会扣成负数
- **写锁超时 10s**：并发写自动排队，不再立即报 `database is locked`
- **登录限流**：同 IP 连续失败 5 次锁定 5 分钟，防止暴力破解
- **Session 过期**：12 小时无操作自动登出
- **生产 WSGI**：waitress 限制最多 8 个并发线程 + 20 连接，防止小服务器进程堆积死机
- **请求超时**：单请求 30 秒上限，慢请求不会无限占用线程

## 🚀 一键启动

### Linux / macOS（服务器）

```bash
git clone <repo-url> components
cd components
chmod +x start.sh
./start.sh
```

脚本会自动：
1. 创建 Python 虚拟环境
2. 安装依赖（flask + openpyxl）
3. 初始化 SQLite 数据库
4. 启动服务，监听 `0.0.0.0:5000`

### Windows（本地测试）

```bat
start.bat
```

## 🛠️ 常见问题

**Q: 服务器没有 Python？**
A: `sudo apt install python3 python3-venv`（Debian/Ubuntu）或 `yum install python3`（CentOS）。

**Q: 端口 5000 被占用？**
A: 修改 `app.py` 最后一行的 `port=5000`。

**Q: 如何备份数据？**
A: 直接复制 `data.db` 文件即可。
